# Chatty

A Minecraft mod that shows what players say as text bubbles above their heads.

Messages appear one character at a time, like dialogue in an RPG, with a short blip sound for each letter.

---

## Features

### Chat Bubbles
- **Floating messages** - chat messages appear above the speaker's head and follow them around.
- **Typewriter-style reveal** - text is shown one character at a time, with a sound for every character.

### Voices
- **Unique voice per player** - your UUID shapes how each letter sounds, so players are recognizable by ear.
- **Shared with others** - other players see and hear your chosen voice and color.

### Voice Settings Screen
Open it with the default key **V** to customize:
- **Text color**
- **Voice sound**
- **Pitch**
- **Sound frequency** - every character, every 2nd, or every 3rd.

### Customization
- **Resource pack voices** - add new voice sounds with simple JSON files in a resource pack.
- **Mod integration** - other mods can add new voice sounds as well.
